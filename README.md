# Fire-Detection-from-Satellite-Images
This project detects fire-prone regions from satellite images using deep learning and provides an interactive Streamlit web app for real-time predictions. It aims to support early disaster prevention, forest fire monitoring, and environmental protection.

# Overview

* Uses CNN-based deep learning model trained on satellite images.

* Classifies input as Fire or No Fire.

* Simple and lightweight Streamlit interface for predictions.

* Deployed for browser-based access.
